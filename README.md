# 🌱 CropTails

> A cozy 2D farming simulator where you can grow crops, explore your farm, and build your own little farming world.

## 🎮 About

**CropTails** is a 2D farming simulator created as a game development project. The game focuses on relaxing gameplay, farming mechanics, exploration, and creating an enjoyable pixel-art-inspired environment.

##  Features

* Plant and grow crops
* Manage and care for your farm
* Explore a 2D farming environment
* Interactive gameplay mechanics
* Crop growth and farming systems
* Day and night cycle mechanics 

## Built With

* **Godot 4**
* **GDScript**
* 2D Game Development

## Project Goals

This project was created to gain hands-on experience with:

* 2D game development
* GDScript programming
* Player movement and interaction
* Game mechanics and systems
* Scene organization
* UI development
* Asset management
